# dB Final Delivery — wydania

Publiczne repozytorium wydań aplikacji **dB Final Delivery** (dB Records):
podpisane i notaryzowane paczki `.zip` w zakładce *Releases* oraz plik `appcast.xml`,
z którego aplikacja pobiera automatyczne aktualizacje (Sparkle 2).

Kod źródłowy aplikacji jest w prywatnym repozytorium. Pobieraj wyłącznie z tej strony.

Instalacja: rozpakuj zip, przenieś `dB Final Delivery.app` do `/Applications`.
Kolejne wersje aplikacja pobiera sama (menu *dB Final Delivery → Sprawdź aktualizacje…*).
